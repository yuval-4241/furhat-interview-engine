# apps/ — Streamlit screens

Run from the repo root with `streamlit run apps/<name>.py`.

| File | What it does |
|---|---|
| `demo_app.py` | Advisor demo of the evaluation pipeline |
| `gesture_review_app.py` | Review the generated listening gestures on the robot (keep/drop, notes) |
| `interaction_app.py` | The earlier live demo: answer by voice, the robot reacts |
| `interaction_log.py` | Logging for interaction_app |
| `demo_question_selection.py` | Which questions get the full reaction + PE cycle in the earlier demo (was session_flow.py) |
